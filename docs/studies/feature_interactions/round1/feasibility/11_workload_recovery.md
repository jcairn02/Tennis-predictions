## Auditor's notes

Load kernels on the match clock: minutes cover 84% / 61% (2014–21) and 88% / 82% (2022–24); women lack minutes in 2014–15. Games-based kernels cover 100%. I-052 is deferred only for its unstated tuning target (M5): declare a price-free target (for example next-match serve residuals, 2013–2018) or fix τ in advance; I-053, I-054, I-055, I-058, I-064 and I-065 inherit that τ. I-060 needs event countries at every level and a continent map. `sets_14d` already counts team ties that have set totals.
