How to read the results

Log loss: lower is better

This scores the probability attached to what actually happened. Correct, confident forecasts earn a better score; confident mistakes receive a larger penalty. A model that always says “50–50” scores about 0.69315.

A 70% forecast for the eventual winner scores about 0.357. A 90% forecast for the loser scores about 2.303. We average that penalty across the matches.

The closing line: a strong benchmark

The source describes these odds as late pre-match prices. We turn each player's price into an implied probability, then scale the pair to sum to 100%, removing the quoted margin proportionally. Exact historical quote timestamps have not been verified.

“Raw” uses that normalized probability directly. “Calibrated” adjusts its confidence using training matches only. Beating logistic regression shows an improvement over our model; beating the closing line is a separate question.

Why train on 2020–2025?

We compared three ways to choose training history before looking at this experiment's 2026 scores. Each strategy predicted the same 7,784 validation matches in 2023, 2024, 2025. To predict a validation season, its model saw only earlier seasons. For example, the six-year strategy predicted 2025 using 2019–2024, then used 2020–2025 for the final 2026 fit.

Latest six calendar years had the lowest validation log loss. Its validation advantage over using all available history was 0.89 milli-log-loss (a log-loss reduction of 0.000889). This is a small advantage, not proof of a universally best training window.

Each row shows that history's best ridge setting from the fixed search. Ridge gently limits the 27 new feature weights to reduce fitting noise. This selection used logistic regression as a proxy; the single paid TabPFN fit uses the selected history, so this experiment cannot determine which history TabPFN itself would prefer.

What was trained, and what was held back?

  1. Men only. Neither model was trained on women's matches. Each training row is one men's singles match.
  2. Choose history before 2026. Candidate training histories were compared using earlier validation seasons ending in 2025. The selected history was then frozen for both models. This uses logistic validation as a practical proxy; one TabPFN fit cannot establish TabPFN's best history length.
  3. Use the same 36 inputs. These are the established 9 inputs, including Elo and serve/return strength, plus the 27 new performance, reliability, recovery and event-condition features. Closing prices, player names and match outcomes are excluded from the input columns.
  4. Fit once, then test in 2026. Model weights stay fixed through the test. Sporting features can update from earlier matches as the season proceeds, following the repaired study's historical availability rules.
  5. Handle player order consistently. One prediction request contains each test match in both player orders. We average the two equivalent win probabilities. That means 3,424 query rows, but only 1,712 distinct test matches.

The logistic model is a probability regression with one coefficient per feature; the 27 new coefficients have a selected ridge penalty. TabPFN uses its pretrained tabular model and the provider's high-effort Thinking procedure. Both are judged on probabilities, using log loss.

How strong is this evidence?

  • 2026 was excluded from this fit and its history selection, but it is not untouched research data. This project's earlier feature study had already examined these years and outcomes.
  • The test covers the available part of 2026. It runs through 2026-08-02; it is not a complete season. The underlying archive also has very little ATP data in 2018.
  • The uncertainty interval groups nearby matches. We compare losses match by match, then group dates into 28-day blocks. The interval describes sampling uncertainty in this test; it does not cover different random seeds, alternative training choices or all previous feature searches. Secondary comparisons are exploratory.
  • The historical timing has limits. Features use reconstructed match days, not exact match timestamps. The new rolling features use earlier days; some established features allow an earlier round in the same event on the same day. Exact historical quote/publication times remain unverified.
  • One fitted configuration is one experiment. Internal Thinking validation is controlled by the provider and is not guaranteed to follow time order. The outer boundary still keeps all 2026 targets out of training.
  • Prediction quality is not a betting profit result. These scores do not measure executable prices, commission, limits or actual returns. Matches ending in retirement follow the study's winner/advancement label; bookmakers can settle them differently.
