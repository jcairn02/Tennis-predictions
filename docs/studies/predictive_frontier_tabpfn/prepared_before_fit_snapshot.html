Current status: waiting for TabPFN access

No TabPFN fit or prediction request has been dispatched for this experiment. The tables below contain only the local logistic models and closing-price benchmarks. There is no TabPFN score yet.

The experiment you requested

13,952 men's matches for training, dated 2020-01-06 to 2025-11-16. 1,712 men's matches for testing, dated 2026-01-04 to 2026-08-02.

TabPFN and the direct logistic comparator will receive the same 36 sporting inputs: the established 9, including Elo and serve/return strength, plus the 27 new features. Neither receives closing prices as model inputs. No women's matches are included.

Training-history choice: the latest six calendar years (2020–2025). This was selected using logistic-regression validation predictions for 2023, 2024 and 2025, with each validation season predicted using earlier seasons only. All 2026 results were excluded from that selection. This is a practical proxy for selecting history before spending the single TabPFN fit; it cannot prove which history TabPFN would prefer.

The comparison scores already available

Lower log loss is better. It rewards assigning a high probability to the outcome that actually happens and penalizes confident mistakes. Always saying “50–50” scores about 0.69315. Each group below uses identical matches for its listed models.

The closing line is the bookmakers' late pre-match price, converted to a probability after removing the quoted margin. “Calibrated” adjusts its confidence using training data only. The Pinnacle quotes cover a small early-season subset, so they are not a full-2026 benchmark.

What happens in the one-fit comparison?

Once access is available, the prepared request uses TabPFN 3.5 Thinking, high effort, log-loss objective, seed 0 and 8 estimators requested. One prediction request includes both player orders for each match; averaging the equivalent probabilities removes arbitrary player-order effects. The final report will compare TabPFN with logistic regression and both closing-line benchmarks, including paired uncertainty intervals.

The fitted model stays fixed through 2026. Pre-match sporting features can incorporate earlier 2026 matches as the season progresses. This is a test of forecasts made before each match, not a forecast of the entire season made on 1 January.

Limits to keep in mind

These are the available 2026 matches, not a complete season. The archive has very little ATP data for 2018. Exact historical price timestamps remain unverified. This project previously examined 2026 outcomes during feature research, so this is a chronological test for this fit, not untouched research data. Prediction scores alone do not establish betting profit.
