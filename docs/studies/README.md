# Studies

Bounded empirical reports belong here, with code in `src/eda/`, artifacts in `data/studies/<study_name>/`, and relevant tests in `test/<study_name>/`. Record question, dataset/version, method, results, limitations, and decision status. A study result is not a production decision.

**Every study also keeps a process log,** `process_log.md` beside its README ([template](process_log_template.md); the owner's default from 9 Oct 2026, [decision](../decisions/2026-10-09-study-process-logs.md)). It records how the conclusions were reached, what was known when each choice was made, and where a flaw would hide, for a future reviewer who may re-design the study.
